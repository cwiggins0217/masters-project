* Project Purpose
This pilot evaluates whether the selected CIS hardening recommendations produce repeatable chagnes in a defined SSH attack outcome without unnecessarily disrupting legitimate system use.

** Primary attack outcome:
- Successful shell access
- Authentication blocked
- Connection terminated
- User not permitted
- Experiment failed for unrelated reason


* Research Question
Do selected Linux CIS hardening recommendation produce repeatable changes in a specified attack outcome unnecessarily disrupting legitimate system use?

* Working Hypothesis
Selected CIS recommendations will affect the SSD password-guessing attack only when they modify a necessary attack condition.

** Possible Outcomes:
- Direct protective effect
- Conditional effect
- No measurable effect
- Operational cost
- Unclear/context-dependent relationship
